The 42 icons: 24px grid, stroke 2, round caps and joins, no fill (the three dots of `more` are the one heavier stroke). These files are the source: `scripts/sync-brand-tokens.mjs` turns them into the `Icon` component the website and the admin portal share. They are drawn in a single ink, `navy` (#2b2a8a); in the interface each icon takes the colour of its text instead. Icons are decorative, so the words beside them carry the meaning. Show a section's icon in a 48px tile (`radius-tile`) on `navy-50` (navy ink) or `saffron-50` (brown ink).
