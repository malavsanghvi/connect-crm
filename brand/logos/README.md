The Weaver mark: a ribbon W in teal, blue and green folding into indigo and lavender, with a sun above. Full colour only; it has no single-ink version. Never recolour, outline, stretch or redraw it.

| File | Use |
| --- | --- |
| `weaver-mark.svg` | The master file. Websites, apps, anything that scales. |
| `weaver-mark-256.png`, `-512.png`, `-1024.png` | The mark on a transparent background, for documents, slides and tools that do not take SVG. |
| `weaver-mark-on-white-1024.png` | The mark on a white square: profile pictures and app icons. |
| `weaver-logo.png` | The full logo (mark, "Weaver", "Community management platform") on a transparent background, for light grounds. |
| `weaver-logo-on-indigo.png` | The full logo on `navy`, the mark on its white tile, for dark grounds. |

Use the mark on `canvas`, `white` or `saffron` as it is; over `navy` or any dark ground, set it on a `white` tile with `radius-logo-tile`. The PNGs are drawn from `weaver-mark.svg` with the real faces by `scripts/brand-logo-pngs.mjs`; run it again after any change to the mark.
