# Admin portal prototype v2 (2026-10-09)

Reference only, never shipped (like the other prototypes). Plan: [../../../ADMIN_REDESIGN.md](../../../ADMIN_REDESIGN.md).

These are the artboards of a claude.ai Design canvas (`canvas.json` is its index; the files are `.dc.html` boards). They need that canvas to open: they are not standalone pages.

| File | Board |
|---|---|
| `Main.dc.html` | Today: the greeting, the role's routine, one box for Niva |
| `Routines.dc.html` | A checklist for each of 15 roles |
| `Giving.dc.html` | Record a payment by asking (household picker, confirmation card) |
| `Events.dc.html` | Event Weaver with Niva beside it (reminder in three languages) |
| `People.dc.html` | Ask your data, then the household card |
| `Marketplace.dc.html` | Starter pack, available and coming-soon products |
| `Setup.dc.html` | Niva runs texting setup; what only a person can do |
| `Rules.dc.html` | How Niva works: four levels, rules, what to build first, decisions |
| `ScreenMap.dc.html` | From 138 screens to 11 workspaces |
| `PhoneToday.dc.html`, `PhoneAsk.dc.html` | The phone screens |
| `Rail.dc.html`, `TopBar.dc.html` | Shared parts |

All people, households and figures are made-up sample data. Prices are deliberately absent (B82). Messages, Learning, Store, Content and Reports have no full board; they appear in the map.
