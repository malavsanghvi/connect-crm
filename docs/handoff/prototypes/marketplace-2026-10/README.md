# Marketplace prototype (2026-10-13)

Reference only, never shipped (CLAUDE.md). The owner accepted all three screens on 2026-10-13; they were built as
crm #234 (catalog) and #235 (screens). Live canvas, private to the owner: https://claude.ai/artifact/9wjvK5UaimqQW2ULoRBZME

- `Main.dc.html`: Settings > Marketplace for a community's admin (request, pause/resume, "tell me when it is ready").
- `Platform.dc.html`: a platform admin turns a product on or off with a reason and a fresh 2FA code; requests; audit.
- `States.dc.html`: every product state, who moves it, what people see, what happens to data.

Files are Design-canvas `.dc.html` artboards; images point at the canvas's own uploaded assets (`/_blob/...`).
